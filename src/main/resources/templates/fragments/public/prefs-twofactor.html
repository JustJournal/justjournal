Two-Factor Authentication

Please log in to change your preferences.

Two-factor authentication asks for a code as well as your password when you log in on the web site. It is off unless you turn it on here.

While it is on, the XML-RPC interface and the older Windows and Unix desktop clients cannot log in, because they have no way to ask for a code. The JSON client API supports it.
