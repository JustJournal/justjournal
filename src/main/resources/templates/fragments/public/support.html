FAQ

Lose your password?

Passwords are encrypted in the database and can not be recovered. Send an e-mail to luke@justjournal.com with your username from the e-mail address you signed up with. I can reset the password for you.

What features are working?

  • Creating and canceling accounts
  • Posting, editing and deleting journal entries. Entries can be written as plain text, Markdown or HTML.
  • Viewing journals at https://www.justjournal.com/users/yourUserName (the username is not case sensitive)
  • Security levels: public, friends and private
  • Drafts
  • Comments, with e-mail notification of new comments
  • Friends: add, remove and read your friends page
  • Favorites
  • Moods, locations, music and tags on entries
  • Tag clouds for each journal and the whole site
  • Calendar and yearly archives for browsing old entries
  • Searching a journal
  • Themes and custom CSS for your journal
  • Preferences: biography, contact information, avatar, pictures, sidebar links and password
  • Picture gallery
  • Only allow the journal owner to view a journal
  • Feeds: RSS 2.0, Atom and JSON Feed (public entries only)
  • Subscribing to other feeds
  • Exporting your journal as PDF or RTF
  • Clients for Windows and Unix-like systems, plus any client that supports the Blogger 1.0 or MetaWeblog API. See Software.
  • Site journal to track server upgrades and new features

What features are you working on?

  • Documentation / manual for Just Journal
  • An option to turn off comment e-mails
  • Self-service password reset
  • More style templates (always)
  • HTML templates (this one is on the back burner)
  • Communities

How do I ask a question or report a bug?

E-mail Luke@justjournal.com. In the subject, please include just journal.
